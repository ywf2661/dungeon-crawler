# 에이전트 회의 진행

주제: `$ARGUMENTS` (비어 있으면 "게임을 더 재밌게 만들고 수익화하기 위해 지금 해야 할 것")

subagent는 다른 subagent를 호출할 수 없으므로, 메인 세션인 네가 사회자로서 아래 순서대로 Agent 도구를 호출한다. 각 단계의 결과를 **요약하지 말고 원문 그대로** 다음 단계 프롬프트에 붙인다.

1. **리서치** — `game-researcher`: 주제와 관련된 흥행 게임을 조사.
2. **기획 + 수익화 (병렬, 한 메시지에서 동시 호출)**
   - `game-planner`: 주제 + 리서치 결과 → 재미 개선 기획안.
   - `game-monetization`: 주제 + 리서치 결과 → 수익화 안.
3. **개발 검토** — `game-developer`: "회의 모드(코드 수정 금지)"로 기획안 + 수익화 안의 구현 규모·리스크·대안 평가.
4. **종합** — `game-director`: 주제 + 1~3단계 결과 전부 → 쟁점 정리, 결정, 실행 계획, `docs/meetings/`에 회의록 저장.

마지막으로 사용자에게 회의록 파일 경로와 총책임자의 "이번 주 바로 할 일", "사용자 결정이 필요한 사항"을 보고한다. 사용자 승인 전에는 코드를 수정하지 않는다.
