# 도박사 전용 이벤트 "야바위 컵" + 전용 유물 "딜러의 장갑" 설계

> 2026-10-02 브레인스토밍 확정본. 도박사 미니게임 두 번째(첫 번째: 뒷골목 카드판,
> `2026-10-02-jester-card-table-design.md`). 카드판 브랜치(`jester-card-table`) 위에 이어서 만든다.

## 목표

카드판(운 + 멈출지 판단)과 다른 손맛 — **눈으로 따라가는 집중력** 미니게임. 보상 유물은
수치 버프가 아니라 **던전(노드맵) 자체를 속이는** 기발한 효과.

## 1부 — 이벤트 "야바위 컵"

### 등장 조건

- `player.job === 'jester'` && `!player.jesterShellSeen`. `showMysteryEvent()` handlers에 **3번 push**.
- **런당 1회.** 이벤트가 뜬 순간 `player.jesterShellSeen = true`.
- `jesterShellSeen`은 마을 체크포인트(`makeTownCheckpoint`)에 포함하고, 예전 체크포인트는 로드 시
  `false`로 채운다(카드판 `jesterTableSeen`과 같은 처리 — 롤백으로 유물이 사라지면 다시 노릴 수 있게).

### 진행

- 손만 남은 딜러(카드판과 같은 존재, 말하지 않음)가 판을 벌인다.
- **판돈** `30 + depth*3`, 황금 도박사(`jester_goldbet`) 2배. 소지 골드 < 판돈이면 앉을 수 없다.
  앉는 즉시 판돈을 내고 `saveGame()`(새로고침으로 무르기 방지).
- **3판을 끝까지** 한다(중간에 멈추기 없음). 매 판:
  1. 컵 3개, 동전은 가운데 컵 아래. 가운데 컵이 들렸다 내려와 동전 위치를 보여 준다.
  2. 딜러가 섞는다 — 판별 횟수/속도: 1판 5회·0.42초, 2판 7회·0.32초, 3판 9회·0.24초(한 번 바꿀 때의 시간).
  3. 플레이어가 컵을 하나 누른다. 그 컵이 들리며 결과 공개.
- **정산(맞힌 횟수 → 수령액, 판돈 포함):** 0 → 0, 1 → 판돈, 2 → 판돈×2, 3 → 판돈×3 + 유물 "딜러의 장갑".
  유물을 이미 가지고 있으면 3 → 판돈×4.
  (무작위로 찍으면 기대 수령액이 정확히 판돈 1배 — 집중한 만큼 이득.)
- **사기꾼**(`jester_debtcollector`): 이벤트 동안 1회 "소매로 슬쩍 들추기" — 섞기가 끝난 뒤 고르기 전,
  컵 하나를 골라 몰래 들춰 동전이 있는지 본다(그 판의 선택은 따로 한다).
- **공정성:** 섞는 순서(어떤 두 컵을 바꾸는지)는 순수 로직이 미리 정하고 화면은 그대로 재생한다.
  눈으로 따라가면 반드시 맞힐 수 있다. 딜러가 몰래 속이지 않는다.

### 연출 (이미지 없이 CSS + Web Animations API)

- 컵 3개가 나란히(가로 슬롯 3칸). 동전은 컵 요소의 자식이라 컵과 함께 움직인다.
- **섞기:** 두 컵이 서로 슬롯을 바꾼다. 하나는 앞쪽으로 크게 호를 그리며(살짝 커짐, 위로 겹침),
  다른 하나는 뒤쪽으로 작게(살짝 작아짐, 아래로) 지나간다. `element.animate()`의 `finished`로 순서대로 잇는다.
- **딜러의 손(🫳)** 이 지금 바꾸는 두 컵 위로 따라 움직인다.
- **공개:** 고른 컵이 들린다(위로 이동). 맞히면 동전이 금빛으로 번쩍, 틀리면 그 컵이 붉게 흔들리고
  이어서 동전이 든 컵이 들려 정답을 보여 준다.
- 맞힌 횟수 표시 ●○○(카드판 연승 표시와 같은 모양).
- 연출 중엔 버튼/컵을 누를 수 없다(카드판과 같은 연타 방지). 연출 타이머는 오버레이가 닫혔으면 아무것도 하지 않는다.
- 3D 평면화 주의(카드판에서 겪음): `preserve-3d` 요소에 `filter`/`opacity`를 걸지 않는다(컵은 3D를 쓰지 않으므로
  해당 없음이 기본 — 3D를 쓰게 되면 지킬 것).

## 2부 — 유물 "딜러의 장갑" (`relic_dealerglove`)

- `type:'wild'`, `eventOnly:true`, `effect:{nodeSwap:true}`.
  설명: "구간마다 한 번, 노드맵에서 아직 가지 않은 칸 두 개의 정체를 서로 바꿔치기할 수 있다."
- 획득 시 슬롯 1칸. 가득 차 있으면 기존 `showRelicSwapPrompt()`. 제단 풀에서는 `eventOnly`로 이미 제외된다
  (카드판에서 추가한 필터).

### 바꿔치기 규칙

- **횟수:** 구간(`player.tierIndex`)마다 1회. 사용 시 `player.nodeSwapTier = player.tierIndex`.
  `nodeSwapTier`도 마을 체크포인트에 포함(롤백되면 그 구간에서 다시 쓸 수 있게).
- **대상 칸:** 현재 구간 지도(`player.nodeMap`)에서 아직 지나지 않은 줄(`rIdx > player.nodeRow`)의 칸 중
  종류가 `combat`/`elite`/`shop`/`rest`/`event`인 칸.
- **제외:** `boss`, `midboss`, `relic`(유물 제단), `curse`(저주 제단). 같은 종류끼리는 바꿀 수 없다.
- 바꿀 수 있는 서로 다른 종류의 칸 쌍이 하나도 없으면 버튼을 숨긴다(예: 고요한 제단 구간).
- 줄이 달라도 된다(뒤쪽 상점을 앞줄로 당겨오기 가능). 연결선(길)은 그대로, 칸의 종류(`type`)만 맞바꾼다.

### 조작/연출

- 유물 보유 + 이번 구간 미사용 + 바꿀 쌍 존재 → 노드맵 진행 표시줄(`#node-map-progress`, "구간 진행 n/m" 옆)에
  "🫳 바꿔치기" 버튼.
- 누르면 바꿔치기 모드: 대상 칸들이 금빛 테두리로 빛나고 나머지는 흐려진다. 안내 "바꿔칠 칸 두 개를 고르세요" +
  "취소" 버튼. 이 모드에선 칸을 눌러도 이동(`pickNode`)하지 않는다.
- 첫 칸 선택 → 살짝 들림. 두 번째 칸(다른 종류만 선택 가능) → 두 칸 아이콘이 야바위 컵처럼 호를 그리며
  엇갈리는 연출(Web Animations API) → 종류 교환 → `saveGame()` → 지도 다시 그리기 → 로그
  "딜러의 장갑으로 [상점]과 [정예 전투]를 바꿔쳤다." 
- **"가려진 지도"(`hideDepth` 유물 효과)와 함께 보유:** 칸이 ???로 보이므로 무엇을 바꾸는지 모른 채 바꾼다
  (따로 처리하지 않음 — 자연스러운 결과). 로그에도 종류를 밝히지 않는다("무언가를 바꿔쳤다").

## 범위 밖

- 딜러가 몰래 속이는 판(정직한 게임만).
