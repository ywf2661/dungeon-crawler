# 도박사 전용 이벤트 "뒷골목 카드판" + 전용 유물 "소매 속 에이스" 설계

> 2026-10-02 브레인스토밍 확정본(A안 — 전용 이벤트 + 승부로 얻는 유물).

## 목표

도박사로 플레이할 때만 겪는 "도박사다운" 순간을 하나 만든다. 물음표 이벤트에서 실제로
판돈을 걸고 짧은 승부를 하고, 끝까지 이기면 도박사 전용 확률 유물을 얻는다.

## 1부 — 이벤트 "뒷골목 카드판"

### 등장 조건

- `player.job === 'jester'`(기본 직업 기준 — 2차 전직 전후, 하이브리드 전부 포함).
- `showMysteryEvent()` handlers에 **3번 push**(다른 이벤트 대비 3배 가중치).
- **런당 1회.** 이벤트가 뜬 순간 `player.jesterTableSeen = true`.

### 연출

- 제목 "뒷골목 카드판". 도입: 회랑 한구석, 낡은 탁자 위에서 카드를 섞는 **손만 남은 딜러**
  (얼굴이 없다 — story.md 8장 7번 "사물이 사람을 흉내 낸다"와 같은 결). 말은 하지 않고
  카드를 내밀거나 판돈 쪽으로 손가락을 까딱인다.
- 직업 무관 이벤트 톤은 기존 물음표 이벤트와 같은 오버레이(`eventOverlay`).

### 규칙 — 하이로우 3연승

- **판돈** `stake = 30 + depth*3` 골드. 황금 도박사(`jester_goldbet`)는 2배.
  소지 골드 < 판돈이면 "판에 앉는다" 버튼 비활성(지나간다만 가능).
- 앉으면 판돈을 먼저 낸다. 매 판: 딜러 카드 1장(1~13 균등) 공개 → 플레이어가 **높다/낮다**
  선택 → 다음 카드(1~13 균등) 공개. 고른 방향으로 **엄격하게** 크면/작으면 승리,
  **같은 숫자는 패배**(딜러의 몫).
- 패배하면 판돈을 잃고 끝.
- 1승 후: "멈춘다"(판돈의 **2배** 수령) / "계속한다".
- 2승 후: "멈춘다"(판돈의 **3배** 수령) / "계속한다".
- **3연승**: 판돈을 돌려받고 유물 "소매 속 에이스" 획득.
- 황금 도박사는 판돈이 2배이므로 수령액도 자연히 2배(배율 자체는 동일).
- **사기꾼**(`jester_debtcollector`): 이벤트 동안 **1회** "패를 바꿔치기" 버튼 — 지금 공개된
  딜러 카드를 새로 뽑는다(높다/낮다 고르기 전에만).
- 확률(시뮬레이션 20만 회, 매번 유리한 쪽 선택): 한 판 승률 71%, 3연승 기본 **36%**,
  사기꾼(애매한 5~9에서 바꿔치기) **42%**.

### 기타

- 유물을 이미 가지고 있으면(이론상 불가 — 런당 1회, 획득 경로 하나) 3연승 보상은 판돈의 4배로 대체.
- 결과는 로그 한 줄 + `saveGame()`. 중간에 새로고침하면 판돈은 이미 낸 상태로 저장되지 않으므로
  (선택 시점에만 저장) 기존 이벤트들과 같은 수준으로 둔다.

## 2부 — 유물 "소매 속 에이스" (`relic_aceinsleeve`)

- `type:'wild'`, 설명: "전투가 시작될 때마다, 다음 운 스킬 하나의 성공 확률이 15%p 오른다."
- `effect:{firstLuckBonus:0.15}`, `eventOnly:true`.
- **효과 구현**: 전투 시작(`combat/battle-setup.js`의 `battleFlags` 초기화 직후)에
  `player.fateBoostChance = Math.max(player.fateBoostChance||0, getRelicSum('firstLuckBonus'))`.
  이 값은 기존 정보료/촉과 같은 1회 보정 장치라, 동전 던지기·승부수·마지막 카드·베팅/올인
  중 먼저 쓰는 스킬 하나가 소비한다(운명의 주사위·야바위는 원래 이 보정을 안 씀).
- 일반 유물처럼 슬롯 1칸. 획득 시 슬롯이 가득 차 있으면 기존 `showRelicSwapPrompt()`로 교체.
- 일반 유물 제단 풀(`RELIC_ALTAR_POOL`)과 그 밖의 무작위 유물 풀에서 `eventOnly`인 것은 제외.
- 유물 도감 등록(`addToRelicDex`)은 다른 유물과 동일.
- 하드코어 묘지 회수(`combat/battle-end.js`의 grave.relics)로 다른 직업이 얻는 것은 막지 않는다 — 운 스킬이 없으면 보정이 소비되지 않아 효과가 없을 뿐이다.

## 코드 배치

- 순수 로직(판돈 계산, 판 결과, 배당, 등장 조건)은 새 파일 `js/jester-table.js`,
  단위 테스트 `tests/jester-table.test.js`(node vm — 기존 테스트와 같은 방식).
- 화면은 `events.js`의 `showJesterTableEvent()`, 풀 주입은 `showMysteryEvent()`.
- 유물 정의/풀 제외는 `relics.js`, 전투 시작 훅은 `combat/battle-setup.js`.
