# 도박사 유물 세트 "딜러의 판" — 보스전을 한 판 승부로 설계

> 2026-10-07. 숨겨진 도박장 2차(`2026-10-07-jester-den-games-design.md`)의 후속.
> **사용자 확정:** 도박사 전용 유물 3개(소매 속 에이스·딜러의 장갑·벼랑 끝의 촛불)를 모으면 보스전(층별보스·
> 중간보스·최종보스 모두)을 전투 대신 미니게임으로 치를 수 있다. **선택제**, 지면 **사망 처리**. 층별보스·중간보스는
> 기존 게임 중 무작위 하나, 최종보스는 또 다른 도박 게임.
> **사용자 부재 중 내가 정한 것(확인 필요):** 아래 "결정 사항" 표.

## 목표

- 도박사 런의 끝에서 "보스를 도박으로 넘긴다"는 파격적인 판타지. 운에 목숨을 거는 순간을 플레이어가 고른다.
- "쌓았다 터뜨리는" 구조가 아니다 — 매 보스전 한 번의 승부.

## 결정 사항 (사용자 부재 중 결정, 바꾸기 쉬운 순서대로)

| 항목 | 결정 | 이유 |
|---|---|---|
| 제안 방식 | 보스전 시작 시 명령 버튼 위에 **"🎲 딜러의 판 — 한 판으로 끝낸다"** 버튼. 첫 행동을 하면 사라진다. 누르면 확인창(건다/그만둔다) | 조우 대사 팝업과 겹치지 않고, "질 것 같을 때 도박으로 도망"을 막는다 |
| 보스전 승리 기준 | 카드판 **2연승**(같은 숫자는 패배), 야바위 **3판 중 2번**, 쥐 경주 **내 쥐가 1등**, 도둑잡기 **승리** | 운 + 실력으로 대략 반반이 되게(카드판 ≈50%, 쥐 경주 배당 1위 ≈45%, 도둑잡기 읽으면 53%). 쥐 경주 "2등 안"은 배당 1위가 77%라 너무 쉬워서 1등으로 |
| 최종보스 게임 | **시간의 스물하나** — 21에 가까운 쪽이 이기는 블랙잭, 보스가 딜러(17 이상까지 받음), 동점은 다시 나눔. **21을 넘었을 때 한 번 시간을 되감아** 방금 받은 카드를 무를 수 있다 | 시간을 붙든 마녀/회랑의 끝과 맞는 "되감기" 비틀기. 되감기 포함 승률 52~54%(시뮬레이션 30만 판). 도박장 스물하나는 카드판과 겹쳐서 뺐지만, 최종보스 전용 한 판으로는 새 경험 |
| 이기면 | 그 자리에서 처치 — 보상·경험치·구간 보스 보상 선택·엔딩은 평소 처치와 **완전히 같다**(최종보스 광폭화 단계는 건너뛴다) | 기존 승리 경로(`checkBattleEnd`) 그대로 재사용 |
| 지면 | HP 0 → 평소 사망과 같다(쉬움/보통 마을 되감기, 하드코어 초기화). 꺼지지 않는 촛불 같은 생존 장치는 **발동하지 않는다** | 사용자 확정("지면 사망") |
| 다시 걸기 방지 | 건 순간 `player.bossGambleUsed = 그 칸 id` 저장 → 그 칸에서는 다시 제안하지 않는다(새로고침으로 패배를 무르고 다시 거는 걸 막음). 새 칸/새 지도에서 초기화 | 사망 처리 저장 전(0.9초)에 새로고침하면 패배가 지워지는 구멍 |
| 세트 완성 장면 | 세 번째 유물을 얻는 순간 1회 대화: 세 소지품이 맞물리고, 작은 **광대 방울** 소리, 딜러가 처음으로 인사하는 시늉 + 기능 안내 | 딜러의 정체(옛 궁정 광대?)는 방울로만 암시 — 새 설정을 확정하지 않는다 |
| 판돈 | 없다(목숨이 판돈) | |
| 전직 효과 | 도박장 게임의 사기꾼 능력(카드 바꿔치기·컵 들추기·발 걸기·훔쳐보기)은 보스전에서도 그대로. 최종보스 게임엔 없음 | |

## 흐름

1. `startBattle()` 끝에서 `showBossGambleOffer()` — 조건(`bossGambleEligible`): 세트 완성 + `enemy.isBoss`(층별보스·파수꾼·
   최종보스 모두 true) + 이 칸에서 아직 안 걸었음. 버튼 행 `#boss-gamble-row`를 보인다.
2. 첫 행동(명령 잠김 = `setCommandsEnabled(false)`)에서 `hideBossGambleOffer()`.
3. 버튼 → 확인창 → "건다" → 명령 잠금, `bossGambleUsed` 저장, 게임 고르기(`bossGambleGame`: 최종보스면 `final21`,
   아니면 4종 무작위) → 게임을 `{boss:true, onResult}`로 연다(판돈 없음, 지나가기 없음).
4. `onResult(won)`: 이기면 배너 → `enemy.phase`를 광폭화 단계 끝으로, `usedUndying=true`, `enemy.hp=0` → `checkBattleEnd()`.
   지면 배너 → `player.hp=0` → `checkBattleEnd()`.

## 코드 배치

- 순수 로직 → `js/jester-den-games.js`(테스트 `tests/jester-den-games.test.js`): `JESTER_SET_RELICS`, `jesterSetComplete(p)`,
  `bossGambleEligible(p, e)`, `BOSS_GAMBLE_GAMES`, `bossGambleGame(e, rng)`, `BOSS_TABLE_STREAK=2`, `BOSS_SHELL_HITS=2`,
  `bjTotal(cards)`, `bjDealerHits(cards)`, `bjOutcome(mine, theirs)`.
- 흐름/최종보스 게임/세트 장면 → 새 파일 `js/jester-boss-gamble.js`.
- 보스전 모드 → `events.js`의 `showJesterTableEvent`/`showJesterShellEvent`, `jester-den.js`의 `showRatRace`/`showThiefGame`에 `opts.boss`.
- 버튼 행 → `index.html`(명령 영역 위), 숨김 훅 → `combat/battle-fx.js`의 `setCommandsEnabled`, 제안 → `combat/battle-setup.js`
  `startBattle()` 끝, 초기화 → `nodemap.js`(`pickNode`/`enterNodeMapTier`), 세트 장면 → `relics.js`의 `finalizeRelicPick` 끝.

## 범위 밖

- 보스전 도박 전용 보상(추가 보상 없음 — 보스 처치 보상 그대로).
- 최종보스별로 다른 게임(지금은 셋 다 시간의 스물하나, 도입 대사만 다름).

## 검증

- 단위: 세트 판정, 제안 조건(보스 아님/이미 걸었음/다른 칸), 게임 고르기(최종보스/난수 경계), `bjTotal`(에이스 1/11),
  `bjDealerHits`(17 경계, 소프트 17), `bjOutcome`(버스트/동점).
- 헤드리스: 세트 + 보스전 → 버튼 보임, 공격하면 사라짐, 세트 없거나 일반 전투면 안 보임 / 걸고 이기면 처치·구간 보스 보상 경로·
  `bossGambleUsed` 저장 / 지면 사망 화면 / 같은 칸 재제안 없음 / 카드판·야바위·쥐 경주 보스전 모드 승패 / 최종보스 스물하나
  (고정 카드) 승리 → 엔딩, 21 초과 → 되감기 1회 / 세트 완성 장면 1회 / 콘솔 오류 없음.
