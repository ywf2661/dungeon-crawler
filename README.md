이 프로젝트는 여러 Claude 계정을 번갈아 사용하면서 개발하고 있다.

첨부한 PROJECT.md와 HANDOFF.md를 먼저 읽어라.

## 작업 규칙

1. PROJECT.md를 통해 프로젝트 전체 구조를 파악한다.
2. HANDOFF.md를 통해 현재 개발 상태와 다음 작업을 파악한다.
3. 전체 소스코드를 처음부터 다시 분석하지 마라.
4. 이번 작업과 직접적으로 관련된 파일만 확인한다.
5. 필요한 파일이 제공되지 않았다면 추측하지 말고 파일명을 요청한다.
6. 관련 없는 파일은 분석하지 않는다.
7. 기존 기능을 임의로 변경하지 않는다.
8. 새로운 라이브러리나 프레임워크를 임의로 추가하지 않는다.
9. 기존 ES Module 구조를 유지한다.
10. 수정 범위를 최소화한다.

특히 중요한 원칙:

PROJECT.md와 HANDOFF.md에 이미 설명되어 있는 내용을
다시 전체 소스코드를 분석해서 확인하려 하지 마라.

현재 작업에 필요한 파일만 확인해라.

먼저 PROJECT.md와 HANDOFF.md를 읽고
현재 프로젝트 상태를 5~10줄 이내로 요약한 다음
이번 작업을 수행하기 위해 추가로 필요한 파일이 있다면
파일명만 알려줘.

아직 코드를 수정하지 마라.
